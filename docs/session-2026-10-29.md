# Session, Oct 28–29, 2026: Flora is rigged

*Captured by Hal. Follows [`session-2026-10-24.md`](session-2026-10-24.md). No game code; the work was Flora's model, in Blender on this Mac.*

## 1. What was built

The artist's straight-tail export hadn't arrived, so Michael asked Hal to rig the sculpt as it is. Hal wrote a headless Blender pipeline, now in [`tools/blender/`](../tools/blender/):

| Script | Does |
|---|---|
| `autorig.py` | sculpt in, game rig out: finds the body's centerline, feet and gill tips from the mesh, decimates to 12k triangles, skins with automatic weights, straightens the swept tail and makes that the rest pose, scales to 22 cm, unwraps UVs, writes `.blend` + `.glb` |
| `views.py`, `head_test.py`, `pose_test.py` | renders for checking a rig without opening Blender: four views, head close-ups with the jaw/gills posed, a full-body bend test |
| `inspect.py`, `fbx_export.py` | inventory of a `.blend`; a Y-up FBX for Maya / 3ds Max |

The result (37 bones) stays in `assets/private/flora/` with the sculpt, since it's the artist's work:

- `head`, `spine_01–03`, `tail_01–08` (bend roll set so side-to-side is one local axis), three bones per leg.
- **`jaw`**: Michael's ask, she has to eat. The sculpt's mouth line was too shallow to find automatically, so its position is an argument read off a measured render; the script cuts a clean lip line along it, and a dark mouth interior appears only when the jaw opens.
- **Gills**: Michael's note that an axolotl normally holds them well swept back but flaps them. Each stalk is a two-bone chain; the rest pose is retracted, and one local axis sweeps it, so the flap is the base bone swinging with the tip lagging.

Checked by render, not by eye in a viewport: closed, jaw open, gills flared, and a full-body pose all deform cleanly (the thin tail fin crumples a little in strong bends). The GLB and FBX re-import with every bone and weight.

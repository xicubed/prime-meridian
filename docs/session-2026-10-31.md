## 2. Decisions

- **Hal is the crew's manager**, from this chat; members are reached only through Herdr. Michael keeps one interface.
- **One shared working tree**, because the game has one world; separate copies per agent would fork it ("a multiverse"). Nothing goes live until Michael approves the commit. `AGENTS.md` and GDD §4.2 now say so.
- **Names:** French, after Claude Monet (crew-up's manager). Grammatical gender says where the model runs: masculine = cloud (`le-`/`un-`), feminine = local (`la-`/`une-`); `un-`/`une-` before a vowel. Job words follow Michael's earlier crew: architecte, automate (builders, one per area), testeur, coureur, critique, docteur.
- **The kit is the starting world**, loaded from a local copy so the original stays intact. Nothing from the kit is committed: the license allows use in this one game and publishing screenshots and the finished product, not sharing the pack, and a public repo would share it.
- Crew members on the Omarchy box work too (a Claude runner answered a roll call there); Hermes isn't installed on the box yet.

## 3. Open

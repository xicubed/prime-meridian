# Quest: click the animal to do its chore; chores in the chat are checkboxes you can untick

**Game:** Prime Meridian. **Asked by:** Michael: "clicking the animal might be better [than
keyboard shortcuts], and maybe in the chat it works like a todo checkbox so you can uncheck it
if you made a mistake." **Led by:** Hal.

## The moment we're building

1. **Click a creature.** The player clicks Flora (or her worm jar), or Juniper, in the 3D scene.
   - If one of its chores is due: it's done exactly as the old F key did it (`world/chore-done`
     with `:via :click`), Hal says a `:chore-done` line, and the hungry bubble goes away.
   - If nothing is due: nothing is logged and Hal says a `:chore-not-due` line with the last
     time it was done and when it's next due, as clock times ("8:16 PM", "8:00 AM"), in the
     player's local time.
   - The pointer turns into a hand over a clickable creature. A drag (camera look) is not a click:
     only a press and release that barely moved (e.g. under 6 px) and are short (under ~400 ms)
     count, so the kit's camera controls still work.
2. **The chat is a todo list.** In the 💭 history, a chore that counted shows as a checkbox
   line: ☑ "Juniper's hay · 8:16 PM", next to Hal's line about it. Unticking it undoes that chore:
   the creature's done-time goes back to what it was before, whatever it consumed comes back
   (a bale, a worm), the hungry bubble returns if it's due again, and Hal says a `:chore-undone`
   line. The box stays in the history unticked (a struck-through line), and it can be ticked
   again, which redoes it if the chore is still due. Undo survives a reload (the history and the
   in-game play state are already saved to localStorage).
3. **No more chore keys.** Remove `:hud :keys` from `resources/estate.edn` and the key handling
   that used it (F and G); keep Escape for closing the 💭 panel.

## What exists (read first)

- `src/pm/content.cljs`: `hal-say`, `hal-on-chore`, `content/hal-lines`. The new events
  `:chore-not-due #{:name :chore :last-at :next-at}` and `:chore-undone #{:name :chore}` are
  in `resources/content/hal-lines.edn` (generated by the content pipeline; never edit it). If a
  line table lacks an event, fall back silently (no caption), as for other events.
- `src/pm/talk.cljs` (pure): the talk log, `observe`, `append`, captions, save/restore,
  `:event` on Hal entries, de-duplication on reload. `src/pm/ui.cljs`: the DOM for captions,
  🔊, 💭 panel. `src/pm/core.cljs`: frame loop, `on-key!`, the play cache (`pm.play.v1`,
  `overlay/play-of` / `apply-play`), the state cache, Hal's state file overlay.
- `src/pm/plan.cljs` / `src/pm/scene.cljs`: placed creatures and their parts (meshes); three.js
  only through `pm.three` (add a raycast helper there if needed).
- Mirrors Hal keeps (`:source :hal`, e.g. Flora) are overwritten by Hal's file when it's newer;
  that's fine: a click or an undo on them changes the game's copy only (write-back to Hal is a
  later round). Don't change that rule.
- Gate: `.crew/gate.sh`. Don't read `assets/private/`, `public/kit/`, `public/state/`.
  Don't edit `resources/content/*.edn`.

## Scope

1. **Pure** (tested): which creature a picked mesh belongs to (from scene data, not names in code);
   `chore-at-click` (the first due chore of that mirror, else a not-due answer with last/next
   times); `undo-chore` / `redo-chore` from a logged event (restoring the previous done-time and
   the consumed amount, which the event must now record); talk entries for chores carry the log
   event id and a `:done?` flag; ticking/unticking in the talk log; the next-due time from
   `:every` (and `:at` if the existing `due?` uses it: match `due?` exactly).
2. **DOM**: pointer pick on the canvas (click vs drag rule above, hand cursor on hover);
   checkboxes in the 💭 panel (a real `<input type="checkbox">` with a label, keyboard
   accessible); undo/redo wired to the pure functions.
3. Remove the chore keys (data and code) and their tests; update tests that pinned them.

## Out of scope

Writing back to Hal's file, the calculator/chat panel, new chores, new creatures.
